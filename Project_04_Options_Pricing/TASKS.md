# Module IV: DeFi Options Pricing

## Project Title
DeFi Options Pricing (Automated Vault Strategy)

## Status
**✅ Completed** — all tasks below finished.

## Objective
To build a pricing model for a "DeFi Option Vault" (DOV) that sells ETH Call Options. We will implement the Black-Scholes-Merton model to price options and calculate "The Greeks" (Delta, Gamma, Theta) to manage hedging risk.
