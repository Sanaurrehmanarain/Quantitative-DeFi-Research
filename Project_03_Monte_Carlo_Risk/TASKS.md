# Module III: Monte Carlo Risk Simulation

## Project Title
Monte Carlo Risk Simulation (DeFi Protocol Solvency)

## Status
**✅ Completed** — all tasks below finished.

## Objective
To engineer a "Stress Testing" engine for a hypothetical DeFi lending protocol. We will simulate 10,000 future price paths for ETH using Geometric Brownian Motion (GBM) to calculate "Value at Risk" (VaR) and Conditional VaR (Expected Shortfall).

---

## Tasks

- [x] Calibrate Drift and Volatility from historical ETH data.
- [x] Run 10,000 simulations for a 30-day time horizon.
- [x] Visualize the "Cone of Uncertainty" (Spaghetti Plot).
- [x] Calculate the probability of ETH dropping below a specific liquidation threshold (e.g., $1,500).
